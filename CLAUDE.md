## Repository Purpose

This is the official Homebrew tap for [payfacto](https://github.com/payfacto) tools. It distributes Ruby formula files that Homebrew uses to install precompiled binaries from GitHub Releases.

End users install via:

```sh
brew tap payfacto/tap
brew tap payfacto/lmsgo
brew install payfacto/tap/bb
```

## Architecture

- Each `*.rb` file at the repo root is a single Homebrew formula. Currently: `bb.rb` (the [bb](https://github.com/payfacto/bb) Bitbucket CLI).
- Formulae point to release artifacts hosted on the upstream tool's GitHub releases (e.g. `https://github.com/payfacto/bb/releases/download/vX.Y.Z/bb_<os>_<arch>.tar.gz`) and pin each artifact by SHA256.
- Formulae cover four platform/arch combinations: macOS intel, macOS arm, Linux intel x86_64, Linux arm64.

## Update Workflow

**Formulae are generated and committed by GoReleaser in the upstream tool's repo — not edited by hand.** The header `# This file was generated by GoReleaser. DO NOT EDIT.` is authoritative. Commit history shows automated bumps like "Brew formula update for bb version vX.Y.Z".

If asked to update a formula manually (e.g. for a hotfix), the `version`, four `url` lines, and four `sha256` lines must all be updated consistently. Mismatched checksums will cause `brew install` to fail for users.

The README's `Formulae` table also lists the current version — keep it in sync when bumping.

## Validation

There is no build, test, or lint configured in this repo. To validate a formula change locally, a user with Homebrew installed would run `brew install --build-from-source ./bb.rb` and `brew test ./bb.rb`. Do not invent CI commands that don't exist.
